## 현재 확인 범위

기존 문서의 소스 정적 분석 기준은 [`0dde981`](https://github.com/YeongSu-Lim/Microprocess-Design/tree/0dde981c3934d60a727740ee7f39a67544625d43)입니다. 이후 **원본 개인 보고서에서 실물 보드 클러스터·D/R 표시 전환·모터 값 연동 검증과 표시 주기 조정 기록을 확인**했습니다. 자세한 내용은 [실물 보드 검증 이력](board-validation-evidence.md)을 참조하세요. 이 GitHub 문서 보강 과정에서 보드 시험을 다시 실행하거나 PWM 파형을 계측하지는 않았습니다.

| 항목 | 확인 결과 | 근거 |
| --- | --- | --- |
| 제어·표시 주기 분리 | Ch0/Ch1 별도 ISR 확인 | `handler.c`, `lpit.c` |
| ADC→속도 상한→PWM | 연산·레지스터 기록 경로 확인 | `motor.c` |
| 클러스터·경고 | 자리 순환과 distance >60 조건 확인 | `seven_segment.c`, `motor.c` |
| 리셋 후 주행 진입 | OFF→P 경로 없음 | `main.c`, `state.c` |
| 실제 주기·출력 품질 | 미측정 | 파형·실험 로그 없음 |
| 통합 동작 이력 | **보드 검증 보고서 존재** | 원본 보고서 pp.5–8의 표시·변수 연동 기록, 사용자 상태별 시험 진술. 당시 펌웨어와 공개 코드 동일성 미확인 |

## 재현 전 우선 검토 사항

| 우선 | 소스에서 발견한 사항 | 영향 / 제안 |
| --- | --- | --- |
| 수정됨 | 헤더의 `Motor.h` 대소문자 문제 | PR #2에서 `motor.h`로 수정. 현재 소스 기준 해결됨 |
| 수정됨 | `CarState_t` 타입 선언 순서 | PR #2에서 선언 순서 수정. 전체 타깃 빌드의 검증과 별개 |
| 높음 | 초기 OFF에서 P로 전환하지 않음 | 시작 경로 설계·시험 필요 |
| 높음 | `Velocity_init()`는 속도 변수만 0으로 변경 | OFF/P 진입 시 PWM 레지스터의 이전 값 잔존 가능성 확인 |
| 높음 | CRUISE에서 제동 해제 분기 없음 | 주석과 실행 분기가 다름 |
| 중간 | Ch1 NVIC 설정 구간도 `NVIC_IPR48` 사용 | 의도한 우선순위와 실제 레지스터 설정 확인 |
| 중간 | Ch0 ISR 내부 ADC busy-wait | 변환 실패·지연 시 실행 시간 영향 확인 |
| 중간 | R에서도 D와 동일한 구동 함수 | 역회전 구현으로 소개하지 않음 |
| 중간 | 가속 시 +200 후 상한 초과 가능 | 경계값에서 속도/PWM 값 확인 |
| 중간 | 좌우 주석 불일치·부분 디바운싱 | 물리 배선과 입력 동작 대조 |

## 추가 계측·재현 시험 계획 — 기존 보드 시연과 별개

| 시험 | 입력·조건 | 기록할 증거 |
| --- | --- | --- |
| 시작·정지 | 리셋, 시동 ON/OFF, 기어 입력 | 상태 값, C0V, 실제 PWM 파형 |
| ADC와 PWM | ADC 0·중간·4095, 가속·제동·타력 | ADC/속도/C0V 로그와 듀티 |
| 타이밍 간섭 | 제어·표시 동시 동작, ADC 처리 | ISR 진입/종료 GPIO 파형, 최대 실행 시간·지터 |
| 클러스터 | 기어별 표시, 속도·거리 경계 | 사진/영상과 내부 변수 대응 |
| 경고등 | 거리 60·61·99→0 | PTD15 상태와 표시 영상 |
| 예외 경로 | CRUISE 제동, R 출력, 동시 버튼 | 기대 동작 대비 실제 결과 |

예상 결과와 실측 결과를 구분해 기록하고, 모든 시험에 보드·펌웨어 커밋·클럭·계측 조건을 붙입니다. 사진·보고서는 학번·연락처·팀원 개인정보와 공개 권한을 검토한 뒤 추가합니다.
