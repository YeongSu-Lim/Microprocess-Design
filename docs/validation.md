2026-10-08 기준 main의 [`0dde981`](https://github.com/YeongSu-Lim/Microprocess-Design/tree/0dde981c3934d60a727740ee7f39a67544625d43)을 정적으로 분석했습니다. 이번 작업은 문서 초안이며 실행 코드 변경, 펌웨어 빌드, 보드 실행, 오실로스코프 측정을 수행하지 않았습니다.

## 재현 전 우선 검토 사항

| 우선 | 소스에서 발견한 사항 | 영향 / 제안 |
| --- | --- | --- |
| 높음 | 실제 파일은 `motor.h`, include는 `Motor.h` | 대소문자 구분 환경 빌드 문제 |
| 높음 | `CarState_t` 사용이 typedef보다 앞섬 | 타입 선언 순서 검토 |
| 높음 | 초기 OFF에서 P로 전환하지 않음 | 시작 경로 설계·시험 필요 |
| 높음 | `Velocity_init()`는 속도 변수만 0으로 변경 | OFF/P 진입 시 PWM 레지스터의 이전 값 잔존 가능성 확인 |
| 높음 | CRUISE에서 제동 해제 분기 없음 | 주석과 실행 분기가 다름 |
| 중간 | Ch1 NVIC 설정 구간도 `NVIC_IPR48` 사용 | 의도한 우선순위와 실제 레지스터 설정 확인 |
| 중간 | Ch0 ISR 내부 ADC busy-wait | 변환 실패·지연 시 실행 시간 영향 확인 |
| 중간 | R에서도 D와 동일한 구동 함수 | 역회전 구현으로 소개하지 않음 |
| 중간 | 가속 시 +200 후 상한 초과 가능 | 경계값에서 속도/PWM 값 확인 |
| 중간 | 좌우 주석 불일치·부분 디바운싱 | 물리 배선과 입력 동작 대조 |

## 향후 보드 시험 계획 — 아직 미실시

| 시험 | 입력·조건 | 기록할 증거 |
| --- | --- | --- |
| 시작·정지 | 리셋, 시동 ON/OFF, 기어 입력 | 상태 값, C0V, 실제 PWM 파형 |
| ADC와 PWM | ADC 0·중간·4095, 가속·제동·타력 | ADC/속도/C0V 로그와 듀티 |
| 타이밍 간섭 | 제어·표시 동시 동작, ADC 처리 | ISR 진입/종료 GPIO 파형, 최대 실행 시간·지터 |
| 클러스터 | 기어별 표시, 속도·거리 경계 | 사진/영상과 내부 변수 대응 |
| 경고등 | 거리 60·61·99→0 | PTD15 상태와 표시 영상 |
| 예외 경로 | CRUISE 제동, R 출력, 동시 버튼 | 기대 동작 대비 실제 결과 |

예상 결과와 실측 결과를 구분해 기록하고, 모든 시험에 보드·펌웨어 커밋·클럭·계측 조건을 붙입니다. 사진·보고서는 학번·연락처·팀원 개인정보와 공개 권한을 검토한 뒤 추가합니다.
