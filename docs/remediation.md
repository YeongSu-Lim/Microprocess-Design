# 코드 수정·검증 계획

[README](../README.md) · [발견 사항의 근거](validation.md)

**이번 PR은 문서만 변경합니다.** 아래는 별도 기능 변경 승인을 받은 뒤 수행할 계획이며 수정 완료 또는 시험 통과 목록이 아닙니다. 우선순위는 재현을 막는 문제와 출력 제어 영향 기준입니다.

| 우선순위 | 현재 문제 | 제안 수정 범위 | 검증·통과 기준 |
| --- | --- | --- | --- |
| P0 · 빌드 | `Motor.h` 대소문자, typedef 이전 타입 사용, 시작/링커/디바이스 파일 누락 | 실제 사용 IDE 환경 복구, include·선언 순서 검토 | 도구·보드 버전을 고정한 clean build 및 경고/링크 로그 확보 |
| P0 · 동작 진입 | 초기 OFF→P 전이 없음 | 시작·정지 요구조건을 정하고 상태 전이 추가 | 리셋→시동 ON→P 도달, 시동 OFF 전이, 동시 입력 시나리오 확인 |
| P0 · 출력 정지 | OFF/P에서 속도 변수만 초기화, CRUISE 제동 해제 없음 | 정지 출력·크루즈 해제 정책을 상태 동작과 일치 | 실제 C0V와 PWM 파형에서 정지 확인, CRUISE 제동 시 의도한 전이·출력 확인 |
| P1 · 실시간성 | Ch1 우선순위 설정 대상 재확인, ISR 내부 ADC busy-wait | IRQ 설정 정정 검토, ADC 완료 대기 상한/비동기 처리 검토 | 두 ISR 최대 실행 시간·지터 계측, ADC 실패 상황에서 제어 정체 여부 확인 |
| P1 · 경계 조건 | 가속 +200 후 상한 초과 가능, CRUISE 상한 재적용 없음 | 요구조건 확정 후 clamp·상한 적용 정책 검토 | ADC 0/중간/4095, 상한 급변에서 내부 속도·PWM 범위 확인 |
| P2 · 통합 | R 방향 반전 없음, 좌우 주석 불일치, 부분 디바운싱 | 교육용 요구 범위 명시, 배선/모드·입력 정책 정리 | R 표시와 물리 출력 구분, 버튼 반복·동시 입력·좌우 출력 시험 |

FTM2의 두 채널은 주기를 공유합니다. 독립 주파수가 필요해지면 자원 재배치를 별도 설계 변경으로 검토해야 합니다. 측정 결과 없이 채널 분리만으로 간섭 제거를 확정하지 않습니다.

공통 기록: 코드 커밋, 보드/클럭/툴 버전, 입력 조건, 예상 결과, 실제 로그·파형, 통과 여부. 수정은 이 문서 PR과 분리하고 기존 이력을 보존합니다.
