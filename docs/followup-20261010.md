## 수정과 영향

- `common.h`: `CarState_t` 정의를 extern 선언 앞에 배치. 독립 include 시 unknown type name 오류를 제거합니다.
- `main.c`, `motor.c`: 실제 파일명 `motor.h`와 include 대소문자를 일치시킵니다.
- 제어 알고리즘·레지스터 값·타이밍은 변경하지 않았습니다. 헤더 경로 및 타입 선언 가시성만 수정합니다. enum 값·extern 형식·함수 본문은 동일합니다.

## 오류와 자료 누락 구분

| 구분 | 확인 내용 | 다음 단계 |
| --- | --- | --- |
| 실제 컴파일 오류 | 타입 선언 순서, Motor.h 파일명 불일치 | 이번 PR 수정 및 호스트 헤더 검사 |
| 실제 상태 경로 누락 | OFF에서 Start_Flag=1이어도 OFF 유지 | OFF→P 진입·플래그 소비 정책 확인 후 별도 수정 |

| 자료 누락 | device_registers.h, SDK·startup·linker·IDE 프로젝트 미확보 | 원본 S32 Design Studio 프로젝트와 SDK 버전 필요 |

확보된 ‘자동차 클러스터 시스템 설명’은 대화 정리 자료로, 원본 상태 전이 요구사항을 확정할 설계 보고서가 아닙니다. 시동 종료 허용 조건과 동시 버튼 처리 정책은 임의로 정하지 않았습니다. [기존 계획](remediation.md)의 ADC 대기·가속 상한·인터럽트 우선순위 검토도 남아 있습니다.

## 기존 동작·알려진 결함 재현 검사 — 정상 동작 검증 아님

명령: `sh tests/run_host_checks.sh` (저장소 루트).

GCC 호스트에서 독립 헤더 문법 검사와 실제 `state.c` + 출력 함수 스텁을 실행했습니다. 테스트 함수 `characterize_existing_behavior_including_known_defects`의 6개 assertion 통과: 시동 후 OFF 잔존, 정지 시 P→D, 이동 중 기어 요청 잔존, D→CRUISE, 크루즈 제동 무시, 시동 해제→OFF. 이는 현행 결함까지 재현하는 검사이며 정상 사양 통과를 뜻하지 않습니다. 테스트는 모터 함수를 대체하므로 PWM 출력을 검증하지 않습니다.

S32K144 대상 전체 빌드, 링크, 플래싱, 보드·오실로스코프 시험은 수행하지 않았습니다.

## 필요한 실제 증빙

1. 원본 IDE 프로젝트, SDK 버전, 빌드 로그와 시동·기어·크루즈 상태표.
2. 보드 배선 사진과 핀맵, LPIT 주기 및 PWM 파형.
3. OFF/P 정지 출력, 브레이크 우선 동작, 동시 입력·채터링 시험 기록.

호스트 도구: GCC 13.3.0 (Ubuntu).
