## 재현 순서

1. 실제 사용했던 S32K144 보드와 개발 환경 정보를 확보합니다.
2. 대상 MCU의 지원 패키지·시작 코드·링커·인터럽트 벡터를 갖춘 프로젝트에 기존 소스를 추가합니다.
3. `Motor.h`/`motor.h` 대소문자와 `common.h`의 타입 선언 순서 문제를 먼저 검토합니다. 수정은 기능 변경과 별도의 승인·커밋으로 관리합니다.
4. 보드 배선과 핀맵, 전원·외부 구동 장치를 원본 회로 자료와 대조합니다.
5. 초기 상태 전이와 PWM 정지 동작을 검토한 뒤 클러스터·ADC·타이머·출력을 단계별 확인합니다.
6. 사용한 커밋·도구 버전·빌드 로그와 측정 결과를 함께 기록합니다.

이 순서는 준비 절차이며 현재 환경에서 빌드·보드 실행을 완료했다는 뜻이 아닙니다. 임의의 IDE 프로젝트나 회로 연결을 만들어 재현 완료로 표시하지 않습니다.
