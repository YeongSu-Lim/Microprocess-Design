# 구현과 통합 의사결정

[README로 이동](../README.md) · [아키텍처](architecture.md) · [검증](validation.md)

## 역할과 근거

클러스터·연료 경고등은 본인 직접 담당, 가속 로직·시스템 통합은 참여 범위입니다. 이는 참여자 설명에 근거하며, 파일 단위로 모든 코드를 단독 작성했다고 주장하지 않습니다. FSM·조향·ADC·초기화 등을 포함하는 전체 시스템은 팀 결과입니다.

## 1. 클러스터와 주기 분리

| 단계 | 내용 |
| --- | --- |
| 요구 | 기어·속도·거리를 6자리 표시기로 출력하면서 주행 제어와 함께 실행 |
| 구조 분석 | 공유 세그먼트 핀으로 여러 자리를 순차 구동하며, 표시 스캔과 제어의 갱신 주기가 다름 |
| 구현 | Ch1에서 `Display_ON()`, Ch0에서 상태·속도·거리 처리. 스캔 인덱스 0~5 순환 |
| 확인 결과 | 호출 분리와 자리별 숫자 분해는 소스에서 확인. 깜빡임·지터·CPU 점유율 개선량은 미측정 |

`Display_ON()`의 표시 순서는 기어→속도 백·십·일 자리→거리 십·일 자리입니다. 속도 표시에는 `current_speed / 1000` 스케일을 사용합니다. 자리 교체 전에 `displayDigitClear()`로 이전 출력을 지웁니다. 이 함수는 Ch1 ISR과 `Display_ON()`에서 중복 호출되지만 이번 문서 작업에서 코드를 변경하지 않았습니다.

**설계의 의미:** 다른 응답 주기를 타이머 채널에 배정한 구조입니다. 실제로 표시 장애가 발생했고 분리 후 제거됐다는 실험 기록은 확보되지 않아 완료된 장애 해결 사례로 서술하지 않습니다.

## 2. 연료 경고등 모사

| 단계 | 내용 |
| --- | --- |
| 요구 | 주행 누적 상태에 따라 경고 LED를 출력 |
| 입력 정의 | 센서 측정 연료량 대신 내부 거리 변수 사용 |
| 구현 | `Distance()`가 속도를 버퍼에 누적. 5,000,000 이상이면 거리 +1, 버퍼 0. 거리 >99이면 0으로 순환 |
| 경고 조건 | `distance > 60`에서 PTD15를 LOW로 출력하여 경고 활성화 |
| 확인 결과 | 조건과 출력 마스크 정적 확인. 실제 소비량·주행거리와의 일치성은 평가 대상이 아님 |

버퍼 초과 잔량은 보존하지 않습니다. 거리 99→0 순환 후 경고가 해제되는 데모 동작입니다. 센서 기반 연료량 추정으로 해석하지 않습니다.

## 3. 가속과 PWM 연결

`DRV_Control()`은 12비트 ADC 값으로 속도 상한을 계산하고 내부 속도를 갱신한 뒤 64비트 중간 곱셈으로 PWM 비교값을 산출합니다.

```c
limited_speed = (max_speed * adcResult) / 4095;
FTM2_C0V = ((uint64_t)current_speed * FTM2_MOD) / max_speed;
```

이 두 줄 사이의 조건 분기와 +200 갱신을 포함한 전체 로직은 [motor.c](../motor.c)를 확인하세요. 이는 MCU 소프트웨어의 출력 제어이며 전력단 설계나 실제 속도 추종 성능 검증은 포함하지 않습니다.

## 4. 기능 통합과 자원 공유

| 자원 | 현재 연결 방식 | 확인할 제약 |
| --- | --- | --- |
| 공유 변수 | `common.h` extern과 `main.c` 정의 | `volatile`만으로 여러 변수의 일관된 스냅샷을 보장하지 않음 |
| LPIT | 표시·제어 채널 분리 | ISR 실행 시간·우선순위 영향 별도 측정 필요 |
| FTM2 | CH0 구동, CH1 서보 | 두 초기화 함수에서 공통 SC/MOD를 설정. 주파수 독립 변경 불가 |
| PTD15 | Motor/turn 초기화에 모두 등장 | 실제 경고 출력 갱신은 `Fuel_Warning()`; 초기화 책임 정리 후보 |
| 입력 잠금 | 일부 버튼에서 `input_lock = 30` | 약 300 ms 명목 잠금. 모든 버튼에 동일하게 적용되지 않음 |

통합 의도는 코드 구조로 설명하되, 충돌 예방 효과나 개선 전후 수치는 계측 자료가 있을 때만 추가합니다.
