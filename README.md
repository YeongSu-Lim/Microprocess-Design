# S32K144 MCU 기반 차량 전장 시스템 제어 시뮬레이션

![Uploading 클러스터 시스템 동작.gif…]()



## 1. 프로젝트 개요
차량의 클러스터(계기판) 및 전장 시스템을 모사한 임베디드 제어 프로젝트입니다. S32K144 MCU를 활용하여 속도계, 기어 상태, 연료 경고등, 그리고 구동 모터를 통합적으로 제어합니다. 

단순한 기능 구현을 넘어, 극한의 환경에서도 오작동 없이 요구되는 동작을 수행하는 **높은 제어 신뢰성 확보**에 중점을 두었습니다. 이를 위해 FSM(Finite State Machine) 기반의 강건한 상태 전이 설계와 하드웨어 타이머 인터럽트 최적화를 적용했습니다.

## 2. 개발 환경 및 타겟
* **MCU:** NXP S32K144
* **Language:** C
* **Target Board:** Cortex-M4F/M0+ EDU KIT

## 3. 핵심 기능
* **차량 클러스터 정보 표시:** 7-세그먼트를 활용한 실시간 기어 단수 및 모터 속도 출력
* **구동 모터 제어:** LPIT(타이머)를 이용한 정밀한 모터 회전 및 정지 제어
* **연료 경고등 시스템:** 특정 조건(상태) 도달 시 LED를 활용한 시각적 경고 알림
* **사용자 입력 및 상태 관리:** 스위치 GPIO 인터럽트를 통한 기어 변속(P, R, N, D) 및 상태 변경

## 4. 핵심 엔지니어링 및 구현 방식

### 4.1. FSM(Finite State Machine) 기반의 안정적인 상태 관리
* `Current State` 변수를 도입하여 시스템의 동작을 정의된 상태(P, R, N, D 및 Error) 내에서만 전이되도록 엄격하게 통제했습니다.
* 스위치 채터링(Chattering)이나 예기치 않은 중복 인터럽트 발생 시에도 시스템이 설계된 논리 흐름을 벗어나 비정상적인 동작을 수행하는 것을 원천적으로 차단하여, 제어 시스템의 예측 가능성과 생존성을 극대화했습니다.

### 4.2. 다이내믹 구동(Multiplexing)을 통한 디스플레이 제어
* 4자리의 7-세그먼트 제어 시, 각 숫자를 매우 빠른 주기로 번갈아 점등시키는 **잔상 효과(Persistence of Vision)** 기술을 적용했습니다.
* 제한된 하드웨어 자원(GPIO 핀)을 효율적으로 분배하면서도, 사용자에게는 정보가 끊기지 않고 연속적으로 출력되는 고품질의 클러스터 환경을 구현했습니다.

## 5. 트러블슈팅 (Troubleshooting)

**[이슈] 7-세그먼트 디스플레이 깜빡임(Flicker) 현상 및 조도 불균형**
* **문제 인식:** MCU의 메인 루프 처리 속도와 디스플레이 갱신 주기가 동기화되지 않아 특정 구간에서 숫자가 깜빡이거나 밝기가 일정하지 않은 현상이 발생했습니다. 특히 구동 모터 제어 루틴이 동시에 실행될 때 디스플레이 갱신이 밀리는 병목(Bottleneck) 현상을 확인했습니다.
* **해결 및 최적화:** 1. 메인 루프(While)에서 폴링(Polling) 방식으로 디스플레이 함수를 호출하던 구조를 버리고, **LPIT(Low Power Iterative Timer) 인터럽트**를 사용하여 일정한 주기로 디스플레이를 강제 갱신하는 비동기 처리 방식으로 아키텍처를 변경했습니다.
    2. 인터럽트 서비스 루틴(ISR) 내에서 잔상 효과를 위한 다이내믹 제어 로직을 독립적으로 수행하도록 분리했습니다.
* **결과:** 타 제어 로직의 연산 부하와 관계없이 일정한 밝기와 선명한 출력을 유지할 수 있게 되었으며, 하드웨어 타이머를 적재적소에 활용하여 실시간 처리(Real-time processing) 능력을 크게 향상시켰습니다.
