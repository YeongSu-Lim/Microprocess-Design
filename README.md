# S32K144 기반 차량 전장 시스템

S32K144 MCU에서 차량의 **시동·주행 상태, 가감속, 크루즈, 조향, 방향 표시, 클러스터**를 통합 제어하는 임베디드 프로젝트입니다. C 언어로 주변장치 레지스터를 직접 설정하고 GPIO 인터럽트, LPIT 타이머, ADC, FTM PWM을 연결했습니다.

## 주요 기능

- OFF / P / D / R / CRUISE 상태에 따른 동작 분리
- 버튼 입력에 따른 시동·기어·가속·제동·크루즈 제어
- ADC 가변저항 입력에 따른 최대 속도 설정
- PWM을 이용한 구동 모터 출력과 서보 조향
- 방향 표시 LED 및 제동 시 LED 표시
- 6자리 7-세그먼트를 이용한 기어·속도·거리 표시
- 누적 거리 변수에 연동한 연료 경고등 모사

속도·거리는 코드 내부에서 계산하는 데모 값입니다. 실차 속도 센서나 실제 연료량을 측정하는 시스템은 아닙니다.

## 제어 구조

초기화 후 메인 루프는 비어 있으며 실제 처리는 인터럽트에서 수행합니다.

| 실행 경로 | 역할 |
| --- | --- |
| PORTA / PORTC 인터럽트 | 버튼 이벤트를 플래그와 조향 모드로 변환 |
| LPIT 채널 0 | 상태 전이·동작, 거리·연료 경고, ADC 읽기, 입력 잠금 감소 |
| LPIT 채널 1 | 표시기를 지우고 시동 상태에서 한 자리씩 갱신 |

타이머 설정은 코드의 40MHz 입력 기준으로 채널 0이 10ms, 채널 1이 0.05ms입니다. 실제 주기는 보드의 클럭 설정과 함께 확인해야 합니다. 별도 RTOS 스케줄러를 사용하는 구조는 아닙니다.

### 상태별 동작

| 상태 | 동작 |
| --- | --- |
| OFF | 내부 속도 변수 초기화 |
| P | 속도 초기화, 조향 중앙 정렬 |
| D / R | 제동 우선 처리, 가속 또는 타력 감속, 조향·LED |
| CRUISE | 현재 속도에 해당하는 PWM 유지, 조향·LED |

기어 전이는 `current_speed == 0`일 때 P → D → R → P 순으로 정의되어 있습니다. 크루즈 버튼은 D와 CRUISE 사이를 전환합니다. 현재 R 상태도 D와 동일한 PWM 제어 함수를 사용하며 모터 회전 방향 반전은 별도 구현되어 있지 않습니다.

### 클러스터와 경고

- 6자리 중 기어 1자리, 속도 3자리, 거리 2자리를 순차적으로 표시합니다.
- 기어 표시 코드는 0=P, 1=D, 2=R, 3=C입니다.
- 거리는 내부 누적값으로 계산하며 0~99를 반복합니다.
- 거리 값이 60을 초과하면 PTD15 경고 LED를 켭니다.
- 일부 버튼에는 `input_lock = 30`을 적용하고 10ms 주기마다 감소시킵니다.

## 주요 핀 구성

| 기능 | 핀 |
| --- | --- |
| 시동 / 기어 | PTA13 / PTA12 |
| 크루즈 / 제동 / 가속 | PTC15 / PTC16 / PTC17 |
| 조향 모드 입력 | PTC13 / PTC12 |
| 가변저항 ADC | PTB0, ADC0_SE4 |
| 구동 모터 PWM | PTD10, FTM2_CH0 |
| 서보 PWM | PTD11, FTM2_CH1 |
| 7-세그먼트 자리 선택 | PTB8~PTB13 |
| 7-세그먼트 a~g | PTD8, PTD9, PTD12, PTD5, PTD13, PTD14, PTD3 |
| 방향 표시 LED | PTE14~PTE16, PTA0~PTA1 |
| 연료 경고 LED | PTD15 |

세그먼트 매핑은 `seven_segment.c`의 실제 출력 로직 기준입니다. 일부 주석의 좌우 방향 표기가 다르므로 조향과 LED 방향은 배선 및 실제 동작을 함께 확인해야 합니다.

## 현재 코드 확인 사항

소스만 내려받아 완성된 펌웨어로 바로 실행할 수 있는 상태는 아닙니다.

- `main.c`와 `motor.c`는 `Motor.h`를 포함하지만 실제 파일명은 `motor.h`입니다. 대소문자를 구분하는 환경에서 일치시켜야 합니다.
- `common.h`에서 `CarState_t`를 typedef보다 먼저 사용하므로 선언 순서를 정리해야 합니다.
- 초기 상태는 OFF이며, 시동 플래그가 켜져도 OFF → P로 바꾸는 전이가 현재 `state.c`에 없습니다.
- `Velocity_init()`는 속도 변수만 0으로 만들고 PWM 비교 레지스터를 직접 초기화하지 않습니다.
- CRUISE 상태에는 브레이크에 따른 해제 분기가 현재 구현되어 있지 않습니다.
- 일부 입력에만 잠금 검사가 적용되므로 모든 버튼에 동일한 디바운싱이 적용된 것은 아닙니다.

이 README는 저장소의 현재 구현을 설명합니다. 보드 실행·통합 검증 결과와 자동 테스트는 포함되어 있지 않습니다.
